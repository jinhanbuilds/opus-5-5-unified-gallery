# Opus 5.5 统一效果图鉴

**从想做的效果出发，看演示，读提示词，再回到原作者。** 这份图鉴把 [MiaAI-Lab 的 100 个 HTML 作品](https://github.com/MiaAI-Lab/Claude-Opus-5.5-100-HTML-Files)与 [22 条动效片库](https://github.com/jinhanbuilds/opus-5-5-motion-gallery)放进同一个可搜索的入口。

**[在线打开融合图鉴（飞书秒搭，无需登录）](https://zcnofdpgpxud.feishuapp.com/app/app_17exzr8eka4/)**

![Opus 5.5 统一效果图鉴首页](docs/preview.png)

## 怎么用

1. **找效果：**按名称、编号、说明、技法或提示词搜索；也可按形式、用途、视觉和动态方式筛选。
2. **看演示：**首页可开启动态预览，卡片进入画面后才播放；滚出屏幕会停止。点开详情，可操作网页作品，或播放、暂停和拖动视频型演示的时间线。
3. **听声音：**卡片预览无声。15 条视频型演示可在详情中手动开启本项目后补的背景音效；关闭详情即停止。其他网页作品的原有声音仍由作品内的控件控制。
4. **读提示词与出处：**详情标明原文或摘录，附原始来源。想看精选 22 条的完整技法拆解，可从页面底部进入旧版片库；动效词典也保留双向链接。

## 两套内容如何融合

**100 个 HTML 案例 + 22 条精选动效 − 4 组共用创意 = 118 个主题。** 那 4 组各保留两个演示版本，因此共有 **122 个演示版本**：15 个视频型效果、103 个网页作品。共用创意是 W01/001、W02/008、W03/015、W04/026。

“视频型效果”是能播放、暂停、拖动时间线的 HTML 演示，不是原作者的视频文件。精选片库的演示按提示词制作，可能使用虚构示例输入；原作者、原文/摘录状态和演示差异见条目详情及 [来源与致谢](CREDITS.md)。

## 在本地运行

需要 Git 和 Python 3。请递归克隆，构建脚本会从两个**固定版本的来源子模块**生成完整静态站点：

```bash
git clone --recurse-submodules https://github.com/jinhanbuilds/opus-5-5-unified-gallery.git
cd opus-5-5-unified-gallery
python3 scripts/build.py
python3 -m http.server 8000 --directory dist
```

浏览器打开 `http://localhost:8000/`。普通的 **Code → Download ZIP 不包含子模块**，所以 ZIP 不能直接构建完整图鉴；直接体验请用上方在线链接。部分精选演示使用在线字体或 Three.js，断网时可能无法完整运行。

## 仓库内容

| 路径 | 内容 |
| --- | --- |
| `src/` | 融合页、分类界面、精选缩略图和可手动开启的背景音效 |
| `data/` | 中文索引与旧版 22 条技法拆解的增量数据 |
| `scripts/` | 从两个来源子模块组装静态站点的构建脚本 |
| `sources/` | 固定提交的 100 案例仓库与 22 条片库子模块 |
| `dist/` | 本地生成的完整站点；不提交到 GitHub |

本仓库不把两个来源仓库的原件再次提交为新仓库文件。原作者内容由各自权利人持有，这里没有授予覆盖全部原作和提示词的统一再使用许可。背景音效由本项目程序生成，没有使用外部歌曲、音效采样或配音；它们也不是 Opus 或原作者作品自带的音轨。
