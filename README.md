## 怎么用

1. **找效果：** 按名称、编号、说明、技法或提示词搜索；也可按形式、用途、视觉和动态方式筛选。
2. **看演示：** 首页可开启动态预览，卡片进入画面后才播放；滚出屏幕会停止。点开详情，可操作网页作品，或播放、暂停和拖动视频型演示的时间线。妙搭中的图片条目标明“图片预览”，点击来源入口可回到原作。
3. **听声音：** 卡片预览无声。原 15 条视频型演示使用本项目后补音效；完整本地版新增 43 条视频型效果使用原作音轨，均需手动开启，关闭详情即停止。妙搭保留代码的两个 Lemo 条目也保留原音轨，图片条目不提供播放控件。其他网页作品的声音由作品内的原生控件控制。
4. **读提示词与出处：** 详情区分原文、摘录、公开配方与创作简报。原 22 条和新增 100 条都有完整技法拆解入口；中文改写模板单独标为编辑整理。

## 两套内容如何融合

**100 个 HTML 案例 + 22 条精选动效 − 4 组共用创意 = 118 个主题。** 那 4 组各保留两个演示版本，因此共有 **122 个演示版本**；按主题分类为 15 个视频型效果、103 个网页作品。共用创意是 W01/001、W02/008、W03/015、W04/026。

以上是历史 118 主题的融合关系。新增 100 条各保留一个原作版本后，合计 **218 个主题 / 222 个演示版本，58 个视频型效果 / 160 个网页作品**。

“视频型效果”是能播放、暂停、拖动时间线的 HTML 演示。原精选 22 条按提示词制作，可能使用虚构输入；完整本地版新增 100 条运行原作源码。妙搭图片条目仍按原作形式参与筛选，实际展示以条目标识为准。作者、公开文本类型、版本与接入差异见条目详情及 [来源与致谢](CREDITS.md)。

## 从 GitHub 运行公开版

无需获取完整原件，也无需安装 Node 依赖。下载或克隆后，可以直接用 Chrome 打开 `site/index.html`，或启动 HTTP 服务：

```bash
git clone https://github.com/jinhanbuilds/opus-5-5-unified-gallery.git
cd opus-5-5-unified-gallery
python3 -m http.server 8000 --directory site
```

浏览器打开 `http://localhost:8000/`。`site/` 是通过验收的公开静态快照，新增部分为 **31 条代码 + 69 条图片**，与妙搭运行文件一致。也可以运行 `npm run build`（或 `python3 scripts/build_public.py`）生成独立的 `dist-public/`。

## 维护完整本地版

完整本地版新增 100 条均可运行。它使用当前维护机器上的 `sources/new-originals/` 原件和依赖快照；这份约 756 MB 的输入没有进入公开仓库。GitHub 中的来源清单、公开文本和 hash 可以核对出处，但不能代替完整快照。

在已经具备完整快照的目录中：

```bash
git submodule update --init --recursive
npm install --ignore-scripts
npm run build:full
python3 -m http.server 8000 --directory dist
```

构建所需 esbuild 固定为 0.21.5；已有安装可设置 `ESBUILD_MODULE`。普通 GitHub ZIP 不包含历史子模块和完整原件快照，但包含可直接运行的 `site/` 公开版。旧作品的部分外部依赖沿用历史实现；新增可运行代码的依赖已本地固定。
