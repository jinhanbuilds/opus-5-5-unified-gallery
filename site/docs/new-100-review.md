## 修复与接入差异

- 原作播放适配器在实际首帧渲染后报告就绪；Avi 动效通过 seek 画出首帧时也报告就绪，避免初始暂停时一直等候。
- 暂停时停止重复重绘，seek 与窗口变化仍会刷新；消除暂停画面随机变化并减少无效绘制。
- 画布在原作完成初始化、得到真实尺寸后重新适配窗口。
- Optical 的窄窗口相机保留作者的室内观察位置，按可用视口调整视野；咖啡墙、艾姆斯房间和反向透视不再因相机落在墙外而空白或严重裁切。
- 216 个运行时 CSS 字体完整封装为 WOFF2；保留字符、字形顺序、映射、字宽和可变轴。对应原始字体 238.05 MB，派生字体 119.22 MB；原始文件保留，普通构建直接复用已核验的派生文件。
- 原作实现、原始音轨和原公开文本均保留。资源路径、SVG 容器、运行库打包、时间线桥接与视口适配见 `new-100-sources.md`。

## 使用与已知边界

可以用 Chrome 双击 `dist/index.html`，或在仓库根目录执行：

```bash
python3 -m http.server 8000 --directory dist
```

然后打开 `http://localhost:8000/`。需要重建时运行 `npm install --ignore-scripts` 和 `python3 scripts/build.py`；已有 esbuild 安装可设置 `ESBUILD_MODULE`。

- 运行验收使用 macOS Chrome，390px 为浏览器窄屏／触控模拟；未做实体手机、Safari 或 Firefox 的完整验收。原作需要键盘的游戏仍需要键盘，宽画幅作品在窄屏中保留留白。
